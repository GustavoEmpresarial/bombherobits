# Eight heroes: pixel art revision

Redrawn with `image_gen.imagegen`, using Aurek, Vesper and Cinder's original portraits as style references and each previous collection portrait as the character design reference. Names and rarity distribution are unchanged.

The active gallery uses `apps/web/public/characters/collection/pixel/`. Previous illustrations are preserved in the parent collection folder. Original Aurek, Vesper and Cinder portraits are restored in the landing page and summon reveal.

Exact generation prompt and source/destination mappings: `eight-heroes-pixel-prompts-2026-10-20.json`.

These are presentation assets; this change does not add the eight designs to the live summon pool or create animated gameplay sprite sheets.

Visual checks: all eight gallery images loaded on the landing page; desktop gallery and 375px mobile gallery inspected. Transparent alpha verified on all eight PNGs. Gallery preview: `apps/web/public/characters/collection/pixel/collection-preview.png`.
